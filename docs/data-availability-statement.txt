A workflow video and de-identified non-pixel metadata for the 18 prospective Adaptive stop-and-complete sessions are publicly available at https://github.com/K1mjiang/OrthoReg-World. The public archive contains source-faithful audit records, analysis-support tables, schemas, checksums, and a non-pixel verification script. It does not include the Fixed-k=10 comparison packages, the constrained-randomization schedule, application source code, Enterprise API integration, raw images, video, depth data, screenshots, patient data, credentials, or licensed third-party assets. The formal 36-run Adaptive-versus-Fixed experiment reported in the manuscript was a prospective constrained-randomized comparison; its comparative run packages are outside the downloadable 18-session metadata archive.
