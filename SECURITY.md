# Security and disclosure

This repository contains only the public OrthoReg-World project documentation,
a de-identified non-pixel metadata supplement for 18 Adaptive phantom sessions,
and the accompanying integrity and verification materials.

Do not open a public issue containing:

- credentials or service tokens;
- internal endpoints or enterprise service identifiers;
- private application code or logs;
- device serial numbers;
- operator identities;
- non-public research data; or
- raw visual frames that have not completed privacy review.

If a security concern could expose restricted information, use GitHub private
vulnerability reporting when available or contact the project owner privately.

The private OrthoReg application and its enterprise integrations are outside
the scope of this repository.
